# clipref

Clip encode/decode helpers for ref payloads in pipelines.

**Site:** https://theworker02.github.io/clipref/

## Install / run

```bash
git clone https://github.com/theworker02/clipref.git
cd clipref
node src/cli.js
node --test
```
